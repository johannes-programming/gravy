Overview
--------

This project calculates the GRAVY score of an amino acid sequence.

Installation
------------

To install ``gravy``, you can use ``pip``.
Open your terminal and run:

.. code-block:: shell

    pip install gravy

Typing
------

This project is strictly typed with ``mypy``.

.. container:: versionadded

    **Added in version 1.1.**

Features
--------

``gravy.core``
""""""""""""""

The functions in ``gravy.core`` can also be imported directly from ``gravy``.

``calculate: Final[Callable[..., float]] = score``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This module variable is an alias for score included for legacy.

``main(args: Iterable[str] | None = None) -> int``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This function implements the CLI.

.. code-block:: shell

    # CLI
    python3 -m gravy CYIQNCPLG
    # output: 0.33333
    # the formatting can be changed with the option '--format-spec'

.. container:: versionchanged

    **Changed in version 1.3:** ``main`` is now a function instead of a ``click.command``. It never raises any ``BaseException``, but gives feedback as an ``int``.

``parse_args(args: Iterable[str] | None = None) -> argparse.Namespace``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This function parses CLI ``args``.

.. container:: versionadded

    **Added in version 1.3.**

``run(seq: Iterable[object], *, format_spec: str = ".5f") -> None``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. container:: versionadded

    **Added in version 1.2.**

``score(seq: Iterable[object]) -> float``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This function calculates the GRAVY score.

.. code-block:: python

    # python
    import gravy
    x = gravy.score("CYIQNCPLG")
    y = format(x, ".5f")
    print(y)
    # output: 0.33333
    # the same format as the default in the CLI

``gravy.tests``
"""""""""""""""

``test() -> unittest.TextTestResult``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This project can be tested through its ``test`` function.

The following code can also be executed by running the project's ``run_tests.py``:

.. code-block:: python

    from __future__ import annotations

    __all__: list[str] = []

    import sys

    import gravy.tests


    def main() -> int:
        return int(not gravy.tests.test().wasSuccessful())


    if __name__ == "__main__":
        sys.exit(main())
